# YuZa Studio

Static website for [yuzastudios.com](https://yuzastudios.com): studio home, app pages, privacy policies, and support. Plain HTML and CSS, committed in this repository. No cookies, no analytics, and no third-party scripts.

## App Store status

`data/apps.json` is the only place that decides whether an app is live. Set `live` to `true` on an app that already has an `appleId` and the page renders Apple’s official black Download on the App Store badge, unmodified, linking to `https://apps.apple.com/app/id<appleId>`. Any other state shows the text “Coming soon to the App Store” and does not link to the store. As of 16 October 2026 every app is `live: false` (Chroma Clear and Receiptly still have no Apple ID).

Background themes are CSS variables on `html`. Leave `data-theme` unset for the current warm page. `data-theme="a"` is white with cool-grey bands (`#FFFFFF` / `#F5F6F8`). `data-theme="b"` is dark navy (`#0E1420` page, `#161D2B` cards). `data-theme="c"` is a citrus wash (`#FFFBEF` page, white cards, green accent).

Screenshots and icons are the real files in `assets/apps/`. Forge’s images are already marketing frames, so the site does not put them inside a second phone. Receiptly has an icon and no screenshots. `js/site.js` adds scroll reveals, staggered card entrances, and a slight parallax on the hero phones. It does not set cookies or call the network. With reduced motion, or if the script does not run, the content stays still and visible.

## GitHub Pages

`.github/workflows/pages.yml` deploys this repository to GitHub Pages on every push to `main` (and when the workflow is run manually). Pull requests run the site check and do not deploy.

Once, in the repository settings, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**. After the first successful deployment, confirm the custom domain `yuzastudios.com` and turn on **Enforce HTTPS** when the certificate is ready.

## Privacy and support text

Forge Strength, CantoTalk, and Little Atlas policies are ported from [clam-legal](https://github.com/wzsgrmsz9g-png/clam-legal) commit `11022ca696cadcdf383b490ab1ca47581511e4f6`. The brand Clam / ClamStudio is replaced with YuZa Studio, and `support@clam.app` is replaced with `support@yuzastudios.com`. The legal substance of those policies is otherwise unchanged.

Forge already states that in-app purchases are processed by Apple. CantoTalk also has in-app purchases, and its privacy page adds this line, which was not in clam-legal:

> Purchases are processed by Apple.

Receiptly and ChromaClear have no policy in clam-legal. Their privacy pages say a product-specific policy has not been published and do not describe data practices.

## Local preview

From the repository root:

```bash
python3 -m http.server 8080
```

Open `http://127.0.0.1:8080/`.

HTML is generated by `python3 scripts/build_site.py`. After editing copy, regenerate and run `python3 scripts/check_site.py`.
